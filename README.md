# Resentment React Website

React + Vite website for Resentment.

## Pages
- `/` — Home
- `/services` — Services
- `/case-studies` — Case Studies
- `/contact` — Contact

## Vercel
Build command: `npm run build`
Output directory: `dist`

`vercel.json` includes a rewrite so direct page URLs work with the single-page React app.

## Important
The case-study numbers are placeholders and should be replaced with verified client results before publishing.
