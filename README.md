# Resentment React Test

This is a deliberately small React + Vite test project.

## Vercel

Import the GitHub repository into Vercel. The expected settings are:

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

No environment variables are required.

If the deployed page says **React is working**, the React/Vite/Vercel setup is ready for the full Resentment website.
